What is Cybersecurity?

Cybersecurity is the practice of protecting computers, mobile devices, networks, applications and digital information from unauthorized access, attacks, damage or theft.

Example: When you protect your phone with a strong password and avoid suspicious links, you are practising basic cybersecurity.

Why is Cybersecurity Important?

  • It protects personal information.
  • It helps prevent financial fraud.
  • It protects organizations and businesses.
  • It helps keep computer systems available and reliable.

PART A – ENGLISH EXPLANATION

1. What is a Computer?

A computer is an electronic device that accepts data as input, processes the data according to instructions, stores information and produces useful output.

Example: When you use a calculator on your phone and enter 5 + 5, the phone processes the numbers and displays 10.

2. Data and Information

Data means raw facts that have not yet been processed. Examples include numbers, names, words and measurements.

Information is data that has been processed and organized so that it becomes meaningful.

Example:
Data: 40, 50, 60.
Information: The average of these three numbers is 50.

3. Main Functions of a Computer

A computer performs four major functions:

INPUT

↓

PROCESSING

↓

OUTPUT

↓

STORAGE
  • Input: Receiving data from a user or another device.
  • Processing: Working on the data using instructions.
  • Output: Presenting the result to the user.
  • Storage: Saving data and information for future use.

Example: When you type a document:

  • Input: You type using a keyboard.
  • Processing: The computer handles the typed characters.
  • Output: The words appear on the screen.
  • Storage: You save the document on the device.

4. Hardware

Hardware refers to the physical parts of a computer that you can see and touch.

Examples of hardware:

  • Monitor – Displays information.
  • Keyboard – Used for typing.
  • Mouse – Used to control the pointer.
  • CPU – Processes instructions.
  • Hard drive or SSD – Stores files and programs.
  • RAM – Temporarily holds data currently being used.
  • Motherboard – Connects major computer components.

5. Software

Software is a collection of programs and instructions that tells computer hardware what to do. You cannot physically touch software.

Examples:

  • Windows – An operating system.
  • Android – An operating system.
  • Microsoft Word – A word-processing application.
  • Google Chrome – A web browser.
  • Antivirus programs – Software that helps detect and prevent malware.
Important difference:
Hardware = Physical parts of a computer.
Software = Programs and instructions that run on the computer.

6. Understanding the CPU

CPU means Central Processing Unit. It is the main processor of a computer. It executes instructions and performs calculations.

The CPU has important internal parts, including:

  • Control Unit (CU): Directs and coordinates operations.
  • Arithmetic Logic Unit (ALU): Performs arithmetic and logical operations.
  • Registers: Very small, very fast storage locations inside the CPU.

7. Understanding RAM

RAM means Random Access Memory. It temporarily holds data and programs that the computer is actively using.

RAM is generally volatile memory. This means its contents are lost when power is switched off.

Example: When you open a browser, some of the data needed by the browser is loaded into RAM.

8. Storage: HDD and SSD

Storage devices keep files, applications and operating systems for long-term use, even when the computer is switched off.

  • HDD: Hard Disk Drive. Uses spinning magnetic disks.
  • SSD: Solid State Drive. Uses flash memory and has no spinning disks.
  • Flash drive: A portable storage device.
  • Memory card: A small storage device commonly used in phones and cameras.

9. Operating System

An operating system (OS) is system software that manages computer hardware and software resources and provides services for applications.

Examples: Windows, Linux, macOS and Android.

Common responsibilities of an operating system include:

  • Managing files and folders.
  • Managing memory and running programs.
  • Controlling hardware devices.
  • Providing a user interface.
  • Supporting security features and user accounts.

10. Why Computer Fundamentals Matter in Cybersecurity

Cybersecurity students must understand computers before studying security attacks and protection techniques.

  • Understanding files helps you protect important data.
  • Understanding operating systems helps you manage system security.
  • Understanding networks helps you learn how devices communicate.
  • Understanding software helps you recognize unsafe applications.
  • Understanding hardware helps you identify physical security risks.

Lesson 3: Operating Systems Fundamentals

1. Learning Objectives

By the end of this lesson, students should be able to:

  • Define an Operating System (OS).
  • Explain the major functions of an OS.
  • Identify common operating systems.
  • Understand files, folders, users and permissions.

2. What is an Operating System?

An Operating System (OS) is system software that manages computer hardware and software resources. It provides an environment where applications can run and users can interact with a computer.

Hausa Explanation

Operating System (OS) wani babban manhaja ne da ke kula da aikin kwamfuta. Yana haɗa mai amfani da kwamfuta da kayan cikin kwamfuta (hardware), sannan yana taimaka wa sauran manhajoji su yi aiki.

Examples: Windows, Linux, macOS, Android and iOS.

3. Major Functions of an Operating System

  • Process Management: Controls running programs and tasks.
  • Memory Management: Allocates and manages RAM.
  • File Management: Organizes files and folders.
  • Device Management: Controls devices such as keyboards, printers and storage drives.
  • Security Management: Helps control access to the computer and its resources.
  • User Interface: Allows users to interact with the computer.

Bayani a Hausa

  • Process Management: Kula da manhajojin da suke aiki.
  • Memory Management: Kula da yadda ake amfani da RAM.
  • File Management: Tsara fayiloli da manyan fayiloli (folders).
  • Device Management: Kula da na'urorin kwamfuta.
  • Security Management: Kare kwamfuta da hana mutanen da ba su da izini shiga.
  • User Interface: Hanyar da mutum yake amfani da ita wajen mu'amala da kwamfuta.

4. Types of User Interfaces

Graphical User Interface (GUI): Allows users to interact through windows, icons, menus and buttons.

Command-Line Interface (CLI): Allows users to interact by typing commands.

Hausa: GUI yana amfani da hotuna, maballai da menus. CLI kuma yana amfani da rubuta umarni (commands).

5. Common Operating Systems

  • Microsoft Windows: Commonly used on personal computers.
  • Linux: Widely used on servers and in cybersecurity laboratories.
  • macOS: Apple's operating system for Mac computers.
  • Android: Used on many smartphones and tablets.
  • iOS: Apple's mobile operating system for iPhones.

6. Files, Folders and File Systems

A file stores information such as documents, pictures, videos or programs. A folder organizes files. A file system controls how data is stored and retrieved on a storage device.

Hausa: File na ɗauke da bayanai kamar hotuna ko takardu. Folder kuma yana taimakawa wajen tsara files. File system yana tsara yadda ake adana bayanai da dawo da su.

7. User Accounts and Permissions

A user account identifies a person using a computer. Permissions determine what that user is allowed to read, change, create or delete.

Administrator: A user with elevated privileges to manage the system.

Standard User: A user with more limited permissions.

Hausa: User account yana bambance masu amfani da kwamfuta. Permissions kuma suna bayyana abin da kowane mutum yake da izinin yi. Administrator yana da iko mafi girma fiye da Standard User.

8. The Booting Process

Booting is the process of starting a computer and loading its operating system into memory.

  1. The computer is powered on.
  2. Firmware (BIOS or UEFI) initializes hardware.
  3. The bootloader starts loading the operating system.
  4. The operating system initializes system services.
  5. The login screen or desktop appears.

Hausa: Booting shi ne tsarin kunna kwamfuta da loda Operating System har kwamfuta ta shirya amfani.

9. Operating Systems and Cybersecurity

Cybersecurity professionals must understand operating systems because many security tasks involve managing users, permissions, updates, processes, files, logs and network settings.

  • Keep the operating system updated.
  • Use strong passwords.
  • Limit administrator privileges.
  • Install trusted software only.
  • Enable appropriate security protections.

Hausa: Masu aikin cybersecurity dole su fahimci Operating System domin kare kwamfuta, sarrafa izini, binciken matsalolin tsaro da gano abubuwan da ba su dace ba.

10. Practical Activities

  1. Identify the operating system on your computer or phone.
  2. Open the file manager and create a folder called Cybersecurity Practice.
  3. Find out whether your account is an Administrator or Standard User.
  4. Identify where your device displays its operating system version.

Lesson 4: Computer Networking Fundamentals

Learning Objectives – Manufofin Darasi

PART A – ENGLISH EXPLANATION

1. What is a Computer Network?

A computer network is a group of two or more computers or digital devices connected so they can communicate and share information or resources. Devices may connect using cables (wired) or radio signals such as Wi-Fi (wireless).

Example: A home Wi-Fi network connects phones, laptops and smart TVs to a router so they can communicate with one another and access the internet.

Internet Service Provider

2. Why are Networks Used?

  • Communication: Devices exchange information.
  • Resource sharing: Users can share printers, files and internet connections.
  • Central management: Organizations can manage users and systems centrally.
  • Remote access: Authorized users can access services from other locations.

Security warning: Sharing must be controlled. A network that is not properly secured can expose private files and devices to unauthorized people.

3. Types of Networks

PAN – Personal Area Network: A very small network around one person, such as a phone connected to wireless earbuds using Bluetooth.
LAN – Local Area Network: A network within a limited area, such as a home, office, school or computer laboratory.
MAN – Metropolitan Area Network: A network that can cover a town or city, often connecting multiple LANs.
WAN – Wide Area Network: A network covering large geographical areas. The internet is the best-known example of a global network of networks.

Remember: These names describe the general geographical scope of a network. Real networks can be designed in different ways.

4. Common Network Devices

  • Router: Connects different networks and forwards data between them. A home router commonly connects the home network to the internet.
  • Switch: Connects devices inside a wired LAN and forwards local network traffic to the appropriate device.
  • Modem: Connects to an internet service provider's access technology and converts signals as required by that connection. Some home devices combine a modem and router.
  • Wireless Access Point (AP): Allows wireless devices to join a network, usually through Wi-Fi.
  • Network Interface Card (NIC): Hardware that enables a device to connect to a network, through Ethernet or Wi-Fi.

5. Wired and Wireless Connections

Wired networking: Uses physical cables, commonly Ethernet. It can provide stable and fast connections, but devices need a cable connection.

Wireless networking: Uses radio signals, such as Wi-Fi or Bluetooth. It offers mobility, but signal quality and security settings matter.

6. IP Address and MAC Address

IP address (Internet Protocol address): A logical address used to identify an interface on an IP network so data can be delivered to the right network destination. IPv4 addresses look like 192.168.1.10. IPv6 addresses are longer and use hexadecimal characters.

MAC address (Media Access Control address): A link-layer address associated with a network interface. It is commonly shown as six pairs of hexadecimal digits, for example 00:1A:2B:3C:4D:5E. Some devices use randomized MAC addresses for privacy.

Key difference: An IP address is used for communication at the network layer and may change depending on the network. A MAC address is used on the local network link and identifies a network interface there. Neither should be treated as a password or proof of a person's identity.

7. DNS and DHCP

DNS – Domain Name System: Helps translate human-readable domain names, such as example.com, into IP addresses used by computers to locate services.

DHCP – Dynamic Host Configuration Protocol: Automatically provides network settings to devices, commonly including an IP address, subnet information, default gateway and DNS server.

Simple example: When a phone joins Wi-Fi, DHCP may give it a local IP address. When the user enters a website name, DNS helps the phone find the address of that website's server.

8. TCP, UDP and Ports

TCP – Transmission Control Protocol: A transport protocol that establishes a connection and provides reliable, ordered delivery of data.

UDP – User Datagram Protocol: A transport protocol that sends datagrams without setting up a TCP-style connection. It has lower overhead, but does not itself guarantee delivery or order.

Port number: A number used by transport protocols to direct traffic to the correct application or service on a device. A port is not a physical socket.

  • HTTPS: Commonly uses TCP port 443; modern HTTP/3 uses QUIC over UDP port 443.
  • DNS: Commonly uses port 53 over UDP or TCP, depending on the operation.
  • SSH: Commonly uses TCP port 22 for secure remote administration.

9. What Happens When You Open a Website?

  1. Your device connects to a network, often using Wi-Fi or mobile data.
  2. It uses DNS to find the IP address associated with the website name, if it is not already known.
  3. Your device sends network traffic toward the server, through routers and other network equipment.
  4. The browser and server communicate using the relevant web protocols. HTTPS protects the connection using encryption and authentication.
  5. The server sends data back and your browser displays the page.

10. Basic Network Security

  • Use WPA2-AES or WPA3 security on Wi-Fi where supported; avoid open Wi-Fi for sensitive activity.
  • Change default router administrator passwords.
  • Keep router firmware and connected devices updated.
  • Use a strong, unique Wi-Fi password and do not share it publicly.
  • Turn off features such as remote administration if they are not needed.
  • Only scan or test networks that you own or have clear permission to assess.

  • Central management: Cibiyoyi za su iya kula da na'urori da masu amfani daga wuri guda.
  • Remote access: Mutumin da aka ba izini zai iya shiga wasu ayyuka daga wani wuri.

Gargaɗin tsaro: Dole ne a kula da yadda ake raba bayanai. Idan ba a tsare network ba, wanda ba shi da izini zai iya samun damar ganin fayiloli ko na'urori.

3. Nau'ikan Network

PAN – Personal Area Network: Ƙaramin network da ke kusa da mutum, misali haɗa waya da wireless earbuds ta Bluetooth.
LAN – Local Area Network: Network da ke cikin ƙaramin wuri kamar gida, ofis, makaranta ko computer laboratory.
MAN – Metropolitan Area Network: Network da zai iya rufe gari ko birni, yana haɗa LAN da dama.
WAN – Wide Area Network: Network da ya ratsa manyan yankuna ko ƙasashe. Intanet misali ne na babbar hanyar sadarwa ta duniya.

4. Na'urorin Network

  • Router: Yana haɗa networks daban-daban kuma yana tura bayanai zuwa inda ya dace. Router na gida yakan haɗa network na gida da intanet.
  • Switch: Yana haɗa na'urori a cikin LAN ta cable, sannan yana tura bayanai zuwa na'urar da ta dace.
  • Modem: Yana taimaka wa na'ura ta haɗu da fasahar sadarwar kamfanin internet service provider. Wasu na'urori suna haɗa modem da router a jiki guda.
  • Wireless Access Point: Yana ba na'urorin Wi-Fi damar shiga network.
  • NIC: Kayan cikin na'ura da ke ba ta damar haɗuwa da network ta Ethernet ko Wi-Fi.

5. Wired da Wireless

Wired: Haɗin network ne ta hanyar cable, misali Ethernet. Yana iya ba da haɗi mai ƙarfi da sauri, amma na'ura tana buƙatar cable.

Wireless: Haɗi ne ta siginar iska kamar Wi-Fi ko Bluetooth. Yana ba mutum damar motsawa, amma dole a kula da ƙarfin sigina da tsaro.

6. IP Address da MAC Address

IP Address: Adireshi ne na sadarwa da ake amfani da shi wajen gano inda za a aika bayanai a IP network. Misalin IPv4 shi ne 192.168.1.10. IPv6 kuma yana da tsari mai tsawo.

MAC Address: Adireshin network interface ne da ake amfani da shi wajen sadarwa a local network. Yawanci yana kama da 00:1A:2B:3C:4D:5E. Wasu wayoyi suna iya canza MAC address domin kare sirrin mai amfani.

Bambanci: IP address yana taimakawa wajen isar da bayanai tsakanin networks, kuma yana iya canzawa idan an sauya network. MAC address ana amfani da shi a haɗin local network. Babu ɗayansu da ya kamata a ɗauka a matsayin password ko cikakkiyar shaida ta ainihin mutum.

7. DNS da DHCP

DNS: Yana taimakawa wajen mayar da sunan website kamar example.com zuwa IP address domin na'ura ta iya gano server.

DHCP: Yana ba na'ura network settings kai tsaye, kamar IP address, subnet, default gateway da DNS server.

Misali: Idan waya ta haɗu da Wi-Fi, DHCP zai iya ba ta IP address. Idan ka rubuta sunan website, DNS zai taimaka wajen gano adireshin server ɗin.

8. TCP, UDP da Ports

TCP: Hanyar sadarwa ce da ke kafa haɗi kuma tana taimakawa wajen tabbatar da cewa bayanai sun isa cikin tsari.

UDP: Hanyar sadarwa ce da ke aika bayanai ba tare da kafa irin haɗin TCP ba. Tana da ƙarancin ƙarin nauyi, amma ba ita kaɗai ke tabbatar da isar da bayanai ko tsarinsu ba.

Port Number: Lamba ce da ke taimaka wa kwamfuta tura bayanan da suka shigo zuwa manhaja ko service ɗin da ya dace. Port ba ramin zahiri ba ne.

  • HTTPS: Yawanci TCP port 443; HTTP/3 kuma yana amfani da QUIC ta UDP port 443.
  • DNS: Yawanci port 53 ta UDP ko TCP gwargwadon aikin.
  • SSH: Yawanci TCP port 22 domin gudanar da na'ura daga nesa cikin tsaro.

9. Me ke faruwa idan ka buɗe Website?

  1. Wayarka tana haɗuwa da network ta Wi-Fi ko mobile data.
  2. DNS yana taimakawa wajen gano IP address na website.
  3. Na'urarka tana aika bayanai zuwa server ta hanyar routers da sauran kayan network.
  4. Browser da server suna sadarwa. HTTPS yana amfani da encryption da tabbatar da sahihancin haɗi.
  5. Server yana dawo da bayanai, browser kuma ya nuna shafin.

10. Muhimman Dokokin Tsaron Network

  • Yi amfani da WPA2-AES ko WPA3 a Wi-Fi idan na'urarka tana tallafa musu.
  • Canza password na asusun admin na router daga wanda aka sa tun farko.
  • Sabunta firmware na router da sauran na'urori.
  • Yi amfani da password mai ƙarfi kuma kada ka raba shi a fili.
  • Kashe remote administration idan ba ka buƙatarsa.
  • Kada ka gwada ko bincikar network da ba naka ba sai kana da izini bayyananne.

Lesson 5: Linux and Windows Command-Line Fundamentals

Learning Objectives – Manufofin Darasi

By the end of this lesson, you should be able to explain what a terminal and shell are, navigate folders, inspect basic system and network information, understand simple file permissions, and use safe commands on a computer you own or are authorized to manage.

A ƙarshen darasin, za ka iya bayyana terminal da shell, zagayawa cikin folders, duba wasu bayanan kwamfuta da network, fahimtar izinin files, da amfani da umarnin da ba sa lalata bayanai a kwamfutar da kake da izinin amfani da ita.

PART A – ENGLISH EXPLANATION

1. What is a Command-Line Interface (CLI)?

A Command-Line Interface (CLI) is a text-based way of communicating with an operating system. Instead of selecting icons and menus, a user types a command and the system responds with text.

A terminal is the application or window where you type commands. A shell is the program that reads commands and asks the operating system to carry them out. Windows Command Prompt (CMD), PowerShell, and common Linux shells such as Bash are examples of command environments.

User types a command
↓
Terminal displays the session
↓
Shell interprets the command
↓
Operating system performs an allowed task
↓
Result appears on screen

Hausa: CLI hanya ce ta amfani da rubutattun umarni domin sadarwa da Operating System. Terminal shi ne taga ko manhajar da ake rubuta umarni a ciki. Shell kuma shi ne shirin da ke karanta umarnin ya miƙa shi ga Operating System.

2. Opening a Command Window

Windows: Open the Start menu, type cmd to open Command Prompt, or type PowerShell to open PowerShell. You do not need administrator mode for the beginner commands in this lesson.

Linux: Open the Terminal application from the applications menu. On many desktop distributions, Ctrl + Alt + T opens a terminal, but the shortcut may differ.

Hausa: A Windows, ka buɗe Start menu ka rubuta cmd ko PowerShell. A Linux, ka buɗe manhajar Terminal. Kada ka buɗe da Administrator ko sudo sai idan akwai takamaiman dalili kuma ka fahimci abin da umarnin zai yi.

3. Understanding Command Structure

A command often contains a command name, an option (also called a flag or switch), and sometimes a target such as a file or folder.

Example: ping -n 4 127.0.0.1
ping is the command; -n 4 asks Windows to send four requests; 127.0.0.1 is the computer's own loopback address.

Commands can behave differently in CMD, PowerShell and Linux. Do not assume that a command or option works in every shell. Spaces, quotation marks and spelling matter. A path containing spaces should usually be placed inside quotation marks.

Hausa: Umurni na iya ƙunsar sunan command, ƙarin zaɓi (flag), da sunan file ko folder. Umarnin CMD, PowerShell da Linux ba lallai su zama iri ɗaya ba. Haruffa, tazara da alamun quotation suna da muhimmanci.

4. Basic Windows CMD Commands

dir – Lists files and folders in the current Windows directory.
Hausa: Yana nuna files da folders da ke wurin da kake ciki.
cd – Shows or changes the current directory. Example: cd Documents.
Hausa: Yana nuna ko canza folder ɗin da kake ciki.
cd .. – Moves one folder level up.
Hausa: Yana mayar da kai mataki ɗaya zuwa babban folder.
mkdir Practice – Creates a folder named Practice.
Hausa: Yana ƙirƙirar folder mai suna Practice.
copy notes.txt backup.txt – Copies a file to another name in the current folder. Use only when the source file exists and you understand the destination.
Hausa: Yana kwafe file zuwa wani suna; ka tabbatar da inda za a ajiye kwafin.
type notes.txt – Displays the text content of a text file.
Hausa: Yana nuna rubutun da ke cikin text file.
whoami – Displays the current signed-in user.
Hausa: Yana nuna sunan account ɗin da kake amfani da shi.
hostname – Displays the computer's device name.
Hausa: Yana nuna sunan kwamfutar.

Hausa: Yana nuna bayanan network kamar IP address na kwamfutar.

Hausa: Yana nuna wasu programs da processes da suke gudana.

Hausa: Yana nuna bayanai game da tsarin Windows da kwamfutar.

Hausa: Yana nuna cikakken adireshin folder ɗin da kake ciki.

Hausa: Yana nuna files da folders; -la yana ƙara nuna bayanai da hidden entries.

Hausa: Yana shigar da kai cikin folder mai suna Documents.

Hausa: Yana mayar da kai babban folder ɗin da ke sama.

Hausa: Yana ƙirƙirar sabon folder.
cp source.txt copy.txt – Copies a file. Check the source and destination carefully.
Hausa: Yana kwafe file; ka duba sunan asali da inda za a kai kwafin.
mv oldname.txt newname.txt – Renames or moves a file. Be careful because it changes the file's location or name.
Hausa: Yana canza sunan file ko wurin da yake.

Hausa: Yana nuna rubutun da ke cikin file.

Hausa: Yana nuna sunan na'urar.

Hausa: Yana buɗe bayanin yadda ake amfani da umarnin ls.

6. Files, Folders and Paths

A directory is another name for a folder. A path describes where a file or directory is located.

  • Windows absolute path: C:\Users\Student\Documents
  • Linux absolute path: /home/student/Documents
  • Relative path: A location described from the directory you are currently in, such as Documents/notes.txt.
  • Current directory: The folder your command session is currently using.
  • Parent directory: The folder one level above the current directory.

Some files are hidden by default. In Linux, hidden filenames commonly begin with a dot, such as .config. Windows also has hidden-file attributes. Hidden does not mean secure; permissions and proper protection are still required.

Hausa: Directory na nufin folder. Path kuma adireshin da ke nuna inda file ko folder yake. Absolute path yana nuna cikakken adireshi daga tushen drive ko tsarin fayil; relative path kuma yana dogara da folder ɗin da kake ciki. Hidden file ba yana nufin file ɗin yana da kariya ta musamman ba.

7. Users and File Permissions

Permissions control what a user or program may do with a file or directory. In Linux, the common permission letters are:

  • r – Read: Permission to view or read content.
  • w – Write: Permission to change content.
  • x – Execute: Permission to run a program or, for a directory, access/search it.

Linux permissions can apply to the file owner, a group, and other users. The command ls -l displays permission information. For example, rwxr-xr-- describes read/write/execute for the owner, read/execute for the group, and read-only for others.

chmod changes permissions. For example, chmod u+x myscript.sh adds execute permission for the file owner. Only practise this on a file you created in your own practice folder. Do not change permissions on system files.

Windows also uses file and folder permissions, commonly managed through Properties → Security. An Administrator account can make system-wide changes, so use a Standard User account for ordinary tasks when possible.

Hausa: Permissions suna ƙayyade abin da mutum ko program zai iya yi da file. Read karantawa ne; Write gyarawa ko rubutawa ne; Execute gudanar da program ne. A Linux, izini na iya shafar mai file, group da sauran masu amfani. Kada ka canza izinin system files ba tare da ƙwarewa da izini ba.

8. Using the Command Line for Cybersecurity

Security learners use command-line tools to inspect their own systems. Examples include:

  • whoami – Confirm which account is active.
  • hostname – Identify the device name.
  • ipconfig on Windows or ip addr on Linux – Inspect local network configuration.
  • tasklist on Windows or ps on Linux – Review running processes.
  • ping 127.0.0.1 – Test the local TCP/IP loopback interface. This does not test your internet connection.

These commands help you observe and understand a system. They do not prove that a computer is completely secure. A normal-looking process list or network address is not a full security audit.

Hausa: Masu koyon cybersecurity suna amfani da commands domin duba kwamfutarsu, account, network da programs da ke gudana. Amma sakamakon commands kaɗai ba ya tabbatar da cewa kwamfuta tana da cikakken tsaro.

9. Command-Line Safety Rules

  1. Use commands only on devices and networks you own or have clear permission to test.
  2. Read and understand a command before pressing Enter.
  3. Do not paste commands from unknown websites, messages or videos.
  4. Do not run a command as Administrator or with sudo unless it is necessary and you understand its effect.
  5. Be especially careful with commands that delete, overwrite, format, change permissions recursively, or modify disks.
  6. Back up important files before making system changes.
  7. If a command asks for a password or elevated access unexpectedly, stop and investigate.
Golden rule – Muhimmin ƙa'ida: Never run a command just because someone says it is safe. Understand what it does, what it changes, and whether you have permission.

  3. Windows: Run mkdir Cybersecurity-Practice, then dir to confirm that the folder appears. If it already exists, do not create another one.
  4. Linux: Run pwd, then ls, and identify your current directory and its visible contents.
  5. Linux: Run whoami and hostname to identify the current account and device.
